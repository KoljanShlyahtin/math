# 📚 Шпаргалка по математике 1–11 класс

## 📖 О проекте

Вся школьная математика с 1 по 11 класс — в одном файле. От периметра прямоугольника до интегралов и логарифмов. Проект создан как практика вёрстки (Grid, анимации, адаптивность, тёмная тема) и одновременно как полезный справочник для подготовки к урокам, ОГЭ и ЕГЭ.

**Демо:** открой [`index.html`](index.html) в браузере — или включи GitHub Pages (см. ниже).

---

## ✨ Возможности

- 🧮 **Все формулы с 1 по 11 класс** — арифметика, дроби, ФСУ, тригонометрия, логарифмы, производные, интегралы, стереометрия
- 🔍 **Живой поиск** по формулам, темам и классам с подсветкой совпадений
- 🎛️ **Фильтрация карточек** по категориям: `1–4` / `5–9` / `10–11`
- 📑 **Вкладки (табы)** для тригонометрии, логарифмов, производной и интеграла
- 🌗 **Тёмная / светлая тема** с сохранением выбора в `localStorage`
- 🔢 **Анимированные счётчики** в hero-секции
- 📊 **Прогресс-бары**, запускающиеся при скролле через `IntersectionObserver`
- 🖱️ **Плавная прокрутка** по якорям с учётом высоты шапки
- ⬆️ **Кнопка «Наверх»**, появляющаяся при прокрутке
- 📱 **Полная адаптивность** — мобильные, планшеты, десктоп
- ♿ **Поддержка `prefers-reduced-motion`** для пользователей с ограничениями анимации

## 🧩 Разделы шпаргалки

| Раздел | Что внутри |
|---|---|
| **1–4 класс** | Порядок действий, компоненты действий, периметр, площадь, скорость/время/расстояние, цена/количество/стоимость |
| **5–6 класс** | Обыкновенные дроби, проценты, пропорции, модуль, степени |
| **7–9 класс** | ФСУ, квадратные уравнения, теорема Виета, прогрессии, степени и корни, линейная и квадратичная функции |
| **Геометрия 7–9** | Треугольники (Герон, теоремы косинусов и синусов), четырёхугольники, окружность и круг, теорема Пифагора |
| **Тригонометрия (10)** | Основное тождество, формулы суммы/разности, двойной угол, таблица значений 0°–90° |
| **Логарифмы (10–11)** | Определение, свойства, переход к новому основанию, `lg` и `ln` |
| **Производная (11)** | Базовые производные, показательные, правила произведения/частного, сложная функция |
| **Интеграл (11)** | Табличные интегралы, формула Ньютона-Лейбница |
| **Стереометрия** | Объёмы параллелепипеда, призмы, пирамиды, цилиндра, конуса, шара; площадь сферы |

## 🎨 Кастомизация

### Изменить цвета

Все цвета — в CSS-переменных в `:root` и `body.dark`:

```css
:root {
    --primary: #3498db;   /* основной синий */
    --accent:  #e67e22;   /* оранжевый акцент */
    --success: #27ae60;   /* зелёный */
    --danger:  #e74c3c;   /* красный */
}
```

### Добавить новую формулу

Скопируй блок внутри `.formula-group`:

```html
<div class="formula-card green">
    <h5>Название темы</h5>
    <span class="f">Формула 1</span>
    <span class="f">Формула 2</span>
</div>
```

Классы цвета рамки: `green`, `orange`, `red` (по умолчанию — синий).

### Добавить новую карточку класса

Внутри `#cardsContainer`:

```html
<a class="card" data-category="middle" href="#formulas">
    <svg class="card-icon" viewBox="0 0 40 40">...</svg>
    <h4>Название</h4>
    <p>Описание</p>
    <span class="card-hint">Смотреть формулы →</span>
</a>
```

`data-category` — одна из: `primary`, `middle`, `high`.

### Добавить таб

1. Кнопка: `<button class="tab" data-tab="tab-new">Название</button>`
2. Контент: `<div class="tab-content" id="tab-new">...</div>`

## ⚙️ Ключевые JS-модули

| № | Что делает | Идентификатор |
|---|---|---|
| 1 | Переключатель темы + `localStorage` | `themeToggle` |
| 2 | Анимированные счётчики | `animateCounter()` |
| 3 | Фильтр карточек | `filterBtns` |
| 4 | Табы | `tabs` |
| 5 | Прогресс-бары при скролле | `progressObserver` |
| 6 | Кнопка «наверх» | `toTop` |
| 7 | Плавная прокрутка по сайдбару | `.sidebar a` |
| 8 | Поиск по формулам | `searchBox` |
| 9 | Визуальный отклик на клик карточки | `.card` |
